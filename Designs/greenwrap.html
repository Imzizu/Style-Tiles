/* -----------------------------------------------------------------------------
 * 0. APPLICATION CONTRACT — READ THIS FIRST
 * -------------------------------------------------------------------------- */
This document is a VISUAL LANGUAGE for restyling an existing interface.
It is not a content brief, brand story, product concept, or sample layout to reproduce.

HARD RULES:
1. Keep the host product's copy, labels, navigation, data, images, information architecture, and meaning exactly as they are. Restyle. Do not restory.
2. Do not print this tile's title, catalog name, construction tags, or vibe keywords anywhere in the host UI.
3. Do not invent thematic chrome: telemetry strings, ISO/FREQ/MODE codes, issue numbers, fake metadata, industrial jargon, decorative status lines, sample headlines, or dummy nav items taken from this file or from the Style Tiles catalog.
4. Map existing components onto the visual rules below (color, type, radius, border, shadow, motion). Keep the host's component types; change only their visual treatment.
5. If a decorative motif here would require new copy to make sense, omit the motif. Never add copy to justify a graphic.
6. Do not rename the product, rewrite marketing voice, swap the industry, or add mascots, watermarks, or "system codes" that the host site does not already have.

/* -----------------------------------------------------------------------------
 * 1. VISUAL STATEMENT
 * -------------------------------------------------------------------------- */
A dark luxury field of charcoal canvas with deep-pine and fresh-sage planes stacked as large-radius bento. Light sage slabs invert the ink to botanical green; dark pine slabs carry white and leaf-mint type. Chrome is pill-shaped: buttons, tags, avatars, and nav pods. Elevation is a soft black float plus a faint sage glow, with optional frosted glass at blur(16px). Display is a calm sans with occasional italic serif emphasis inside existing phrases, housed in pill highlights - never new slogans.

/* -----------------------------------------------------------------------------
 * 6. COMPONENT SKIN — APPLY TO EXISTING COMPONENTS
 * -------------------------------------------------------------------------- */
- **Buttons**: Pill geometry. Idle nav/action: dark well #222626, white label. Hover: fill #FFFFFF, ink #121414. Press: scale 0.97. Sage pills may bloom with --glow-sage. Use the host's existing labels.
- **Cards**: Mix pine (#063826), sage (#9BC89E), and neutral dark (#1E2121) slabs at 32px outer / 20px nested radii. 1px white-alpha outlines. Sage slabs use botanical-green ink. Do not add eco stamps, recycling marks, or delivery tags the host lacks.
- **Inputs**: 12px radius wells on dark or sage, 1.5px botanical ring on focus. Input font-size >= 16px.
- **Navigation**: Restyle existing items as pill pods in a frosted or charcoal bar (blur 16px, rgba(30,33,33,0.75)). Active pill inverts to white. Do not add catalog names or decorative status lines.
- **Badges / chips / toggles**: Pills, 8px 18px padding, sage or fog fills. Vertical capsule meters only if the host already has progress or level indicators.
