/* -----------------------------------------------------------------------------
 * 1. VISUAL STATEMENT
 * -------------------------------------------------------------------------- */
A cool, structured light field: pure white canvas, off-white clay cards, and pitch-black inverted wells. Separation is mostly a 1px structural border, with only the softest matte shadow. Outer modules are large 28-32px radii; actions are full pills. Type is compact grotesque - tight tracking on display, uppercase micro labels, tabular mono for figures. The single energetic ink is neon mint against monochrome structure. Hover is a small scale and an inverted icon disc, not a glow bloom.

/* -----------------------------------------------------------------------------
 * 6. COMPONENT SKIN — APPLY TO EXISTING COMPONENTS
 * -------------------------------------------------------------------------- */
- **Buttons**: Full pill. Default: white fill, 1.5px #0A0B0D border, black label, optional circular icon disc. Hover: invert the icon disc, rotate an existing trailing arrow 45deg if present, scale 1.02 with cubic-bezier(0.16, 1, 0.3, 1). Active: scale 0.98, well tint #F0F2F5. Primary filled variant may use mint or pitch-black. Use the host's existing labels.
- **Cards**: 28-32px outer radius, nested 16-20px inner wells, 1px subtle structure plus the base elevation token. Optional frosted glass: rgba(255,255,255,0.75) with blur(12px). Do not add ticker chips, sparkline chrome, or index codes the host lacks.
- **Inputs**: 8px-pill wells, 1px slate hairline. Focus uses 1.5px mint or black ring. Input font-size >= 16px.
- **Navigation**: Restyle existing items as uppercase micro pills or quiet text. Active: mint hairline or mint fill. Do not add catalog names or fake market readouts.
- **Badges / chips / toggles**: Pills with 1.5px ink or mint borders. On inverted surfaces, use 1px white hairline. If the host has charts, inactive series may use mint outline or diagonal hatch; the active series fills #00E58F; siblings dim to 40% opacity.
